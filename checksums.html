Addendum — Release checksums

Addendum ships as one auditable HTML file. To confirm the copy you are running is exactly the code that was published, hash your copy and compare it to the table below. The in-app Settings → Privacy you can verify screen walks through this and also shows the live Content-Security-Policy (connect-src 'none') that structurally blocks all network access.

How to check

On a Mac or Linux computer, in a terminal:

shasum -a 256 index.html

The output must match the SHA-256 for your version exactly. (The same table is recorded as RELEASE-MANIFEST.md alongside the source.)
